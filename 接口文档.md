# 📘 CampusMerch 校园周边定制平台 — API 接口文档

> Base URL: `http://127.0.0.1:8000/api`
> 统一响应格式：`{ "code": 0, "message": "success", "data": ... }`

## 一、认证模块

### 1.1 用户注册

| 项目     | 说明                 |
| -------- | -------------------- |
| **URL**  | `POST /api/register` |
| **认证** | ❌ 无需 Token         |

**请求参数 (JSON)**：

| 字段                  | 类型   | 必填 | 说明                         |
| --------------------- | ------ | ---- | ---------------------------- |
| name                  | string | ✅    | 用户名，最大255字符          |
| email                 | string | ✅    | 邮箱，必须唯一               |
| password              | string | ✅    | 密码，最少8位                |
| password_confirmation | string | ✅    | 确认密码，必须与password一致 |
| phone                 | string | ❌    | 手机号，最大20字符           |

**请求示例**：
```json
{
    "name": "张三",
    "email": "zhangsan@example.com",
    "password": "12345678",
    "password_confirmation": "12345678",
    "phone": "13800138000"
}
```

**成功响应 (201)**：
```json
{
    "code": 0,
    "message": "success",
    "data": {
        "token": "1|abc123...",
        "token_type": "Bearer",
        "user": {
            "id": 1,
            "name": "张三",
            "email": "zhangsan@example.com",
            "role": "user"
        }
    }
}
```

## 五、订单状态机

### 5.1 状态流转图

```
draft(草稿)
  │
  ▼ POST /api/orders
booked(已预订)
  │
  ├─▶ POST /api/orders/{order}/design ──▶ design_pending(待审核)
  │                                            │
  │                          ┌─────────────────┤
  │                          ▼                 ▼
  │               PUT /admin/orders/{id}/review
  │                  approve(通过)        reject(驳回)
  │                     │                    │
  │                     ▼                    ▼
  │               ready(已就绪)        rejected(已驳回)
  │                     │                    │
  │                     ▼                    ▼
  │        POST /api/orders/{id}/complete   重新下单 → booked
  │                     │
  │                     ▼
  │              completed(已完成)
  │
  └─▶ PUT /admin/orders/{id}/review(reject) ──▶ rejected(已驳回)
```

### 5.2 状态枚举值

| 枚举常量       | 值               | 中文   | 说明             |
| -------------- | ---------------- | ------ | ---------------- |
| DRAFT          | `draft`          | 草稿   | 初始状态         |
| BOOKED         | `booked`         | 已预订 | 用户下单后       |
| DESIGN_PENDING | `design_pending` | 待审核 | 用户上传设计稿后 |
| READY          | `ready`          | 已就绪 | 管理员审核通过后 |
| COMPLETED      | `completed`      | 已完成 | 用户确认收货后   |
| REJECTED       | `rejected`       | 已驳回 | 管理员驳回       |

### 5.3 允许的状态转换

| 当前状态       | 可转换到                 |
| -------------- | ------------------------ |
| draft          | booked                   |
| booked         | design_pending, rejected |
| design_pending | ready, rejected          |
| ready          | completed                |
| rejected       | booked                   |

## 九、认证方式

所有需要认证的接口，在请求头中携带：
```
Authorization: Bearer {token}
Accept: application/json
```

Token 通过 `POST /api/login` 或 `POST /api/register` 获取。
